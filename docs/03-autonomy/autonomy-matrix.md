## 4.3 Классы обратимости

- **R1 — полностью обратимо:** rollback деплоя, scale out. До L3.
- **R2 — обратимо с издержками:** рестарт, scale in, reload пула соединений. До L2, до L3 только по данным (§4.5).
- **R3 — необратимо или риск потери данных:** миграции схемы, удаление томов и OSD, рестарт СУБД, изменения Ceph/IPMI/BGP, меняющие топологию. Не выше L1.

## 4.4 Матрица автономности (стартовая, хранится как политика)

Правило: для одного действия уровень в prod не выше, чем в staging. Ограничение «Bare Metal — максимум L2» относится к операциям с железом, хранилищем и сетью. Действия над workload'ами в K8s на Bare Metal подчиняются общей матрице.

| Действие | Класс | Staging | Prod Cloud/Hybrid | Prod Bare Metal |
| --- | --- | --- | --- | --- |
| Rollback canary по статистическому гейту | R1 | L3 | L3 | L3 |
| Scale out stateless в пределах min/max | R1 | L3 | L3 | L3 |
| Scale in | R2 | L3 | L2 | L2 |
| Рестарт пода или Deployment (stateless) | R2 | L3 | L2 | L2 |
| Размер пула PgBouncer (reload) в границах | R2 | L3 | L2, по данным L3 | L2 |
| Параметры СУБД с рестартом (`max_connections`, `shared_buffers`) | R3 | L1 | L1 | L1 |
| Изменение схемы, миграции, рефакторинг хранения | R3 | L1 | L1 | L1 |
| IaC / Crossplane: облачные ресурсы | R2–R3 | L1 | L1 | — |
| Ceph/IPMI/BGP: штатные операции | R2 | — | — | L2 |
| Ceph/IPMI/BGP: необратимые (удаление OSD, переразметка) | R3 | — | — | L1 |
| Удаление данных и бэкапов | — | запрещено | запрещено | запрещено |
| Изменение политик и уровней | — | только человек | только человек | только человек |
| Изменение или удаление записей audit log | — | запрещено | запрещено | запрещено |
